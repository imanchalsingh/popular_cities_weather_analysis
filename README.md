# Popular Cities Weather Analysis

A data analysis project focused on exploring weather patterns across popular cities using Python, data visualization, and exploratory data analysis techniques.

## Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Highlights
- Data Cleaning & Preprocessing
- Temperature Trend Analysis
- Humidity & Rainfall Analysis
- City-wise Weather Comparison
- Seasonal Pattern Exploration
- Data Visualization

## Key Insights
- Compared temperature variations across cities
- Analyzed humidity and precipitation trends
- Identified hottest and coldest cities
- Explored seasonal weather patterns
- Visualized climate differences using charts
